# libusb

libusb is a library for USB device access from Linux, macOS,
Windows, OpenBSD/NetBSD, Haiku, Solaris userspace, and WebAssembly
via WebUSB.

This repository is a fork of libusb. It contains specific changes needed for the use with the blackmagic-debug project.

As the whole blackmagic-debug project has moved to [codeberg](https://codeberg.org/blackmagic-debug/libusb) this repository with the necessary changes is now also maintained on codeberg.
